# 电商用户流失分析报告

> 数据：模拟 1030 名电商用户（含 156 个缺失值、30 条重复行，清洗后 1000 行）
> 方法：Pandas 清洗 → Matplotlib 可视化 → sklearn 逻辑回归
> 复现：`python main_analysis.py`

## 一、数据概况

| 指标 | 数值 |
| ---- | ---- |
| 原始行数 | 1030 行（故意注入脏数据） |
| 缺失值 | 156 个（age / monthly_spend / visit_count 各 50 个，中位数填充） |
| 重复行 | 30 条（按 user_id 去重） |
| 清洗后 | 1000 行，0 缺失 |
| 流失比例 | 约 49% : 51%（流失 : 留存），类别基本均衡 |

## 二、可视化发现

### 1. 流失率随在网时长递减（折线图 output/line_流失率趋势.png）

新用户（在网 1-3 个月）流失率高达 **75%-90%**，随在网时长增长持续下降，36 个月的老用户流失率不足 **15%**。
**结论：流失治理的重心应放在「入网前 6 个月」的新用户留存上。**

### 2. 城市间消费差异平缓（柱状图 output/bar_城市消费.png）

五城市平均月消费在 277-321 元之间，杭州最高、广州最低，差距约 15%。
**结论：城市不是流失的主导因素，不应作为核心特征重点投入。**

## 三、逻辑回归模型

- 划分：训练集 800 行 / 测试集 200 行（stratify 分层抽样，保持流失比例一致）
- 流程：StandardScaler 标准化 → LogisticRegression（Pipeline 串联）
- **测试集准确率：78.5%**，流失类精确率 0.800、召回率 0.777（两类均衡，无偏科）

### 特征影响系数（标准化后，正值促进流失、负值促进留存）

| 特征 | 系数 | 解读 |
| ---- | ---- | ---- |
| 在网时长 tenure_months | **-1.20** | 影响最大：在网越久越稳定 |
| 月消费 monthly_spend | **-1.21** | 消费越高越不容易流失 |
| 年龄 age | +0.20 | 年长用户略易流失（弱信号） |
| 月访问次数 visit_count | +0.13 | 几乎无影响 |

模型学到的规律与业务直觉一致：**低消费 + 新用户 = 高流失风险人群**。

## 四、结论与建议

1. **新用户前 6 个月是留存关键期**，建议对新用户做首月优惠券、活跃任务等干预；
2. **低消费用户流失风险高**，可按消费分位数建立预警名单，配合召回策略；
3. 城市、访问次数对流失影响很小，运营资源不必向其倾斜；
4. 模型可解释性好（系数即业务含义），适合作为流失预警的基线模型；后续可尝试树模型（随机森林/XGBoost）对比，并可加入历史行为类特征提升效果。
